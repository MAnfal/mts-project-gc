I'd avoid using GC AI's API as the key. I don't know of a public one, and even if it exists, it's just another model, so we'd be grading models against a model. I'd go with a model panel plus you as tiebreaker:

3 strong models from different vendors (Opus, GPT, Gemini)
read the FULL text of each candidate rule, vote independently
        │
        ├─ all 3 agree  ──► goes in the key automatically
        └─ they disagree ─► you decide (~5–10 per week, plain-English summary given)
  • Fairness: the panel uses different models with more reading than the contestants get, so it isn't the same model grading itself.
  • Dates need no panel: the official record already has them, so that part of the key is free and fully objective.
  • Cost: about $1–2 per company-week.

Writing up the eval design for the reviewers, I'd call this a "silver" key (model-drafted, human-checked) rather than hand-labeled. That's a small departure from the RFC. Want me to build it this way?
