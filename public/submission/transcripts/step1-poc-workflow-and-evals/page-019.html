Assistant2026-11-21T18:02:07.123Z

scripts/ holds command-line tools you run by hand with npx tsx. The app's UI uses the same code in src/lib/, so these are mainly how I drive things outside the browser:

Group Script What it does
Run evals suite.mts the full eval: every eval set × every setup × 3 runs (running right now)
run.mts one single run, for debugging
arena-rerun.mts re-runs a few failed setups in an existing arena
judge-panel.mts re-judges finished runs after you change judges.yaml, without re-running the pipeline
Build data freeze-week.mts downloads a week of federal rules and freezes it into config/evalsets/weeks/
validate-config.mts checks every config file and lists the eval sets
Read results report.mts prints the dashboard numbers in the terminal
Safety nets snapshot-arena.mts prints the scoreboard as JSON, to prove a refactor changed nothing
record-prompt-fixtures.mts re-records the "prompts didn't change by accident" test after a deliberate prompt change
smoke.mts, smoke-arena.mts cheap checks that each model and search tool still works

For the real build, I'd keep suite, freeze-week, validate-config and judge-panel and drop the rest.
