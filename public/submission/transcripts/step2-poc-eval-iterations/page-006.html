The system still does everything. It reads all ~470 docs, filters them, and flags what it thinks matters, including the dropped ones. "Dropped" never touches the system; it only touches the answer sheet.

Think of it like an exam: - The answer sheet says, for each doc, "should flag" or "should NOT flag". - For a few docs, the two people writing the answer sheet couldn't agree, so that line was left blank. - The system still answers that question. But a blank line has nothing to grade against.

Right now, if the system flags a blank-line doc, we mark it wrong. That's unfair, since nobody knows the right answer. That's the bug.

Two ways to fix it: 1. Skip blank lines when grading: no points, no penalty. 2. Better: you fill in the blanks. You're the GC, so your call becomes the answer. It's about 6 docs.

One small correction to how I described it earlier: "flag or not" is checked by code against the answer sheet. The judge LLMs only grade how well each action is written (clear, accurate, on point).
